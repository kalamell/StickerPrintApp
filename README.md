# Sticker Print — Firebase Auto Print

แอป Windows (.NET 10, WinForms) สำหรับรับงานพิมพ์จาก **Cloud Firestore** แบบ realtime แล้วพิมพ์สติกเกอร์ออกเครื่องพิมพ์ที่เลือกโดยอัตโนมัติ
โปรแกรมเดียวคุมเครื่องพิมพ์ได้ถึง 5 เครื่อง แยกตาม `printerId`

## เครื่องพิมพ์ 1–5 (printerId)

โปรแกรมเดียวคุมเครื่องพิมพ์ได้ **5 เครื่อง** แต่ละเครื่องมีหมายเลข 1–5 ตรงกับ `printerId` ที่ Firebase ส่งมา
และตั้งค่าแยกกันทั้งหมด (เครื่องพิมพ์ / ขนาดกระดาษ / ตำแหน่งข้อความ) ในแท็บ **เครื่องพิมพ์ 1–5**

| job ที่ส่งมา | พิมพ์ที่ |
|---|---|
| `printerId: 1` … `5` (ตัวเลขหรือข้อความ) | เครื่องหมายเลขนั้น (ต้องติ๊ก "เปิดใช้เครื่องนี้") |
| ไม่มี `printerId` | **สลับกันไปทุกเครื่องที่เปิดใช้** 1 → 2 → 3 → … (ค่าเริ่มต้น) หรือตั้งให้ไปเครื่องเดียว / ไม่พิมพ์ ได้ที่แท็บ Firebase |
| `printerId` ของเครื่องที่ปิดอยู่ | ไม่พิมพ์ (มีบันทึกใน log) |

- แต่ละเครื่องมีคิวของตัวเอง เครื่องไหนช้าหรือหลุดไม่ทำให้เครื่องอื่นรอ
- ปุ่ม **คัดลอกกระดาษ+เลย์เอาต์ไป** ใช้ก๊อปการออกแบบจากเครื่องหนึ่งไปอีกเครื่อง

## ออกแบบสติกเกอร์

ค่าเริ่มต้นเป็นแบบนี้: ชื่อ 2 บรรทัด (คำนำหน้า+ชื่อ / นามสกุล) ตัวหนาตัวพิมพ์ใหญ่ → ตำแหน่ง → บริษัท → QR code มุมซ้ายล่าง

แต่ละส่วนกำหนดได้ในตาราง **ตำแหน่งข้อความ**:

| ค่า | ความหมาย |
|---|---|
| X, Y (mm) | วัดจากมุมซ้ายบนของสติกเกอร์ตามขนาดกระดาษที่เลือก (Y = ขอบบนของตัวอักษร) |
| ขนาด (pt) | ขนาดตัวอักษร |
| กว้างสุด (mm) | ข้อความยาวเกินจะย่อให้พอดี (0 = ถึงขอบกระดาษ) |
| ตัวหนา / ตัวใหญ่ / จัดแนว | ซ้าย–กลาง–ขวา (X คือขอบซ้าย/จุดกึ่งกลาง/ขอบขวา) |
| QR code | X, Y และขนาด (mm) — ข้อมูลใน QR ค่าเริ่มต้นคือ `ticket_code` |

- **ลากข้อความหรือ QR ในภาพตัวอย่างทางขวาเพื่อย้ายตำแหน่งได้เลย** (ขยับทีละ 0.5 mm)
- เปลี่ยนขนาดกระดาษแล้วตำแหน่ง/ขนาดทั้งหมดจะย่อ-ขยายตามสัดส่วนให้เอง; กด **รีเซ็ตเลย์เอาต์ตามขนาดกระดาษ** เพื่อกลับไปแบบเริ่มต้น
- Ticket code และ Category ซ่อนไว้ตามแบบ เปิดได้ในตาราง

ฟิลด์ที่ใช้ (เปลี่ยนได้ในแท็บ Firebase): `title`, `first_name`, `last_name` (ถ้าไม่มีจะแยกจาก `fullname`), `position`, `organization`, `ticket_code`, `category`, `printerId`

### ฟอนต์

- ฝังฟอนต์ **IBM Plex Sans Thai** (Regular + Bold) ไว้ในโปรแกรมแล้ว และเป็นค่าเริ่มต้น ทุกเครื่องพิมพ์ออกมาเหมือนกันโดยไม่ต้องติดตั้งฟอนต์
- ใช้ฟอนต์อื่นได้ 3 วิธี: ติดตั้งใน Windows, กด **เพิ่มไฟล์ฟอนต์...** ในแท็บตั้งค่า (คัดลอกไปเก็บที่ `%AppData%\StickerPrintApp\fonts`) หรือวางไฟล์ `.ttf`/`.otf` ในโฟลเดอร์ `fonts` ข้าง `.exe`
- ถ้าฟอนต์มีแค่น้ำหนักเดียว (เช่นมีแค่ `IBMPlexSansThai-Bold.ttf`) ทุกบรรทัดจะใช้น้ำหนักนั้น
- IBM Plex Sans Thai ใช้สัญญาอนุญาต SIL Open Font License 1.1 (`src/StickerPrintApp/Fonts/OFL.txt`)

## สถานะของ job

1. งานที่ยังไม่พิมพ์ = `status == "pending"` (ค่าเริ่มต้น) หรือเลือก `printed == false` ในแท็บตั้งค่าได้
2. ก่อนพิมพ์ แอปจะ claim งานแบบ transaction (`status = "printing"`) จึงไม่มีการพิมพ์ซ้ำแม้มีหลายเครื่อง
3. พิมพ์สำเร็จ → `printed = true`, `status = "printed"`, `printed_at`, `printed_by`, `printed_printer`, `printer`
4. พิมพ์ไม่สำเร็จ → `status = "error"`, `error_message` (สั่งพิมพ์ซ้ำได้จากหน้าจอ)
5. ถ้าต้องการพิมพ์ซ้ำจากฝั่ง backend ให้ตั้ง `status` กลับเป็น `"pending"` (หรือ `printed = false`)

> Service account ต้องมีสิทธิ์อ่าน/เขียน Firestore (เช่น role **Cloud Datastore User**)
> ถ้าปิด "mark printed กลับ Firestore" แอปจะจำ ID ที่พิมพ์แล้วไว้ในเครื่องแทน

## การใช้งาน

1. ดาวน์โหลด `StickerPrintApp.exe` จาก GitHub Actions (artifact `StickerPrintApp-win-x64`) หรือ build เอง (ด้านล่าง)
2. วางไฟล์ Service account `campaign-th---game-xxxx.json` ไว้ข้าง `.exe` (แอปจะหาเจอเอง) หรือกด **เลือกไฟล์...** ในแท็บ **ตั้งค่า**
3. แท็บ **เครื่องพิมพ์ 1–5**: เลือกเครื่อง → ติ๊ก **เปิดใช้เครื่องนี้** → เลือกเครื่องพิมพ์และขนาดสติกเกอร์ → จัดตำแหน่งข้อความ (ทำซ้ำสำหรับแต่ละ printerId)
4. ดูตัวอย่างได้ทันทีทางขวา และลากข้อความเพื่อย้ายตำแหน่งได้
5. กด **บันทึกการตั้งค่า** → **เชื่อมต่อ** แล้วกด **พิมพ์ทดสอบ** เพื่อเช็กตำแหน่ง
   - ถ้าพิมพ์เยื้อง ปรับ **ชดเชยตำแหน่ง X / Y**
   - ถ้าเป็นเครื่องพิมพ์สติกเกอร์ (Zebra, Godex, TSC, Xprinter ฯลฯ) ควรตั้งขนาด Stock ในไดรเวอร์ให้ตรงกับขนาดสติกเกอร์ด้วย
6. เปิด **พิมพ์อัตโนมัติ** ไว้ เมื่อมี job ใหม่เข้ามา แอปจะพิมพ์ออกทันที
   - ถ้าปิดไว้ job จะขึ้นเป็น "รอสั่งพิมพ์" ให้เลือกแล้วกด **พิมพ์ / พิมพ์ซ้ำ รายการที่เลือก**

### เครื่องพิมพ์ Bluetooth

รายการเครื่องพิมพ์ในโปรแกรมมาจากเครื่องพิมพ์ที่ **ติดตั้งใน Windows แล้ว** (USB มักติดตั้งไดรเวอร์ให้อัตโนมัติ)
ส่วนเครื่องพิมพ์ Bluetooth หลังจับคู่ Windows จะสร้างแค่ **COM port** ให้ จึงยังไม่ขึ้นในรายการ ใช้ได้ 2 วิธี:

**ขั้นแรก (ทั้ง 2 วิธี):** Settings → Bluetooth & devices → Add device → Bluetooth → เลือกเครื่องพิมพ์ (ถ้าถาม PIN ส่วนใหญ่คือ `0000` หรือ `1234`)
แล้วดูเลข COM ได้ที่ **More Bluetooth settings → แท็บ COM Ports** (ใช้พอร์ต *Outgoing*; ถ้าไม่มี กด Add → Outgoing → เลือกเครื่องพิมพ์)

**วิธี A — พิมพ์ตรงผ่าน COM port (ไม่ต้องลงไดรเวอร์, แนะนำ)**
1. แท็บ ตั้งค่า → เครื่องพิมพ์ → กด **รีเฟรช** → เลือก `Bluetooth / COM: COM5 (Bluetooth)`
2. **ภาษาเครื่องพิมพ์:** เครื่องพิมพ์ฉลาก/สติกเกอร์ส่วนใหญ่ (TSC, Xprinter XP-xxxB, Gprinter, HPRT, iDPRT) ใช้ **TSPL**; เครื่องพิมพ์ใบเสร็จ/พกพาใช้ **ESC/POS**
3. ตั้ง **dpi** ตามสเปกเครื่อง (ส่วนใหญ่ 203) และ **gap** = ระยะห่างระหว่างดวงสติกเกอร์ (มักเป็น 2–3 mm)
4. กด **พิมพ์ทดสอบ** ถ้าออกมากลับหัวให้ติ๊ก **กลับหัว 180°**; Baud rate ไม่มีผลกับ Bluetooth ใช้ 9600 ได้เลย

**วิธี B — ติดตั้งไดรเวอร์ของยี่ห้อเครื่องพิมพ์** แล้วตั้งพอร์ตของไดรเวอร์เป็น COM port ข้างบน
เครื่องจะขึ้นในรายการเหมือนเครื่อง USB

> เครื่องพิมพ์ที่ใช้ได้แค่ผ่านแอปมือถือ (Bluetooth LE เช่น Niimbot, Phomemo บางรุ่น) จะไม่สร้าง COM port จึงใช้กับ Windows ไม่ได้

### การเชื่อมต่อ

- **Realtime** (ค่าเริ่มต้น) ใช้ Firestore listener (gRPC) ได้งานทันที
- **Polling** ดึงข้อมูลทุก N วินาทีผ่าน HTTPS ปกติ สำหรับเครือข่ายหรือ proxy ที่บล็อก gRPC
  (ถ้าโหมด Realtime ไม่ได้รับข้อมูลภายใน 20 วินาที แอปจะแจ้งใน log)

ไฟล์ตั้งค่าและ log อยู่ที่ `%AppData%\StickerPrintApp\` (`settings.json`, `logs\yyyy-MM-dd.log`)

## Build

ต้องมี [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

```powershell
dotnet build -c Release
# exe ไฟล์เดียว ไม่ต้องติดตั้ง .NET บนเครื่องปลายทาง
dotnet publish src/StickerPrintApp -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `FirestoreJobSource.cs` | เชื่อม Firestore, เลือกเครื่องตาม printerId, claim / mark printed |
| `JobProcessor.cs` | คิวพิมพ์แยกต่อเครื่อง (claim → print → write back) |
| `StickerRenderer.cs` | วาดเลย์เอาต์สติกเกอร์ (ใช้ทั้งพิมพ์จริงและ preview) |
| `StickerPrinter.cs` | ส่งงานไปเครื่องพิมพ์ Windows ด้วยขนาดกระดาษที่กำหนด |
| `RawPrinter.cs` | พิมพ์ตรงผ่าน COM port / Bluetooth (TSPL, ESC/POS) |
| `FontManager.cs` | โหลดฟอนต์ที่ฝังไว้/ไฟล์ฟอนต์โดยไม่ต้องติดตั้ง |
| `PrinterProfile.cs` | ค่าของเครื่องพิมพ์แต่ละเครื่อง + เลย์เอาต์ (X/Y ของแต่ละส่วน) |
| `MainForm.cs` | หน้าจอหลัก / ตั้งค่า / preview (ลากย้ายตำแหน่งได้) |
| `AppSettings.cs` | ค่าตั้งค่า (บันทึกใน `%AppData%`) |
